# Horizon TechX - Image Gallery

This project is a responsive image gallery created as part of my Horizon TechX internship.

The main idea of this project was to build a simple and attractive gallery where users can view images easily and interact with them through basic controls.

# About the Project:

I created this image gallery using HTML, CSS and JavaScript. The design focuses on a clean layout, smooth interactions and a responsive experience across different screen sizes.

# Features:
- Responsive image gallery
- Clean and simple user interface
- Image hover effects
- Lightbox view for images
- Responsive design for different screen sizes
- Easy-to-use gallery controls

# Technologies Used:
- HTML5
- CSS3
- JavaScript
